# Contributing

Contributions that improve reproducibility, tests, documentation, or the Streamlit experience are welcome.

1. Fork the repository and create a focused branch.
2. Install `requirements.txt` and `requirements-dev.txt`.
3. Run the quality checks documented in the README.
4. Keep generated artifacts out of commits unless they are intentionally versioned evidence.
5. Open a pull request with the motivation, implementation, and verification results.

Never submit private property, financial, credential, or personally identifying data.
